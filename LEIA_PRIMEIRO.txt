Branch correta: feature/estudante-3-audio-ocr-imagem-acessibilidade

No Ubuntu, a partir da raiz do projeto, ATUALIZE primeiro a sua branch:
  git fetch origin
  git switch feature/estudante-3-audio-ocr-imagem-acessibilidade
  git merge --ff-only origin/main

Se a branch só existir no remoto:
  git switch --track origin/feature/estudante-3-audio-ocr-imagem-acessibilidade

Se houver alterações locais impedindo troca/merge, NÃO as apague: faça backup ou stash antes.

Depois EXTRAIA o arquivo .zip na raiz do projeto e rode:
  bash scripts/aplicar_parte3_local.sh

NÃO EXECUTE git add, git commit ou git push se quiser apenas revisar as mudanças.
