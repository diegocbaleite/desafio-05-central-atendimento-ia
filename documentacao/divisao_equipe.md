## Material de avaliação fornecido pela equipe

- `entrada_texto.txt`: pedido de efetivação de matrícula, protocolo 2026-000142.
- `entrada_audio.mp3`: solicitação oral correspondente.
- `entrada_pdf-imagem.pdf`: ficha digitalizada de matrícula, para OCR.
- `brasao.png`: símbolo institucional fornecido; manter proveniência distinta de imagem sintética.

**O material foi fornecido nesta conversa, mas não foi enviado ao repositório público**, pois contém identificadores pessoais e ainda não foi confirmado que todos os dados são fictícios. Manter cópias originais inalteradas em ambiente privado; documentar seu hash e registrar divergências encontradas entre modalidades. O endereço de e-mail do texto é diferente do endereço de e-mail pronunciado no áudio; não harmonizar automaticamente.

## Fluxo de trabalho Git
1. Desenvolver e testar na branch de cada estudante.
2. Abrir pull request para `main` com descrição, testes e evidências.
3. Revisar conflitos e executar os testes antes de aceitar o merge.
4. Não alterar os gabaritos para combinar com a saída do modelo.
5. Nenhuma minuta será enviada automaticamente e nenhuma avaliação simulada será apresentada como revisão humana real.
